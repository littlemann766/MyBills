Notifications

Control bill and reminder alerts in the Android app.
Bill alerts can be scheduled from the due date itself up to 31 days early. Reminder alerts use the date and time saved on each reminder. Sound choices are previewed in the app and will fire while this page is open. When running as a normal browser/download page, Android controls notification sound and cannot wake this page after it is closed; exact closed-app alerts require the installed Android app notification bridge.

Android App Security

PIN or biometric locking needs to be added in the Android package so it can use the phone's secure lock screen. The web version does not store a fake PIN.
