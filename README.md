# My Bills 20.0.132

This build consolidates the recent patch stack instead of layering another conflicting theme on top.

- One authoritative navy/cyan/light theme with working whole-app color controls.
- Net/Available Now and Monthly Budget use the v99 cash-budget ledger so paid-in-advance bills are counted in the month they were actually paid.
- Monthly Snapshot uses the same ledger, so its numbers match Budget/Available Now.
- Spending Week/Month, Edit, Delete, and paid-bill labels are handled by one renderer.
- Bill Colors is a single collapsed Calendar section.
- Extra safe scrolling space is kept above the bottom navigation.
- Android asset HTML and root HTML are identical.
- No icon/image files are included.
